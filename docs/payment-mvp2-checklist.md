# Payment и Legal Checklist для MVP 2

MVP 1 не должен хранить деньги, внутренний баланс или полные данные карт.

Перед подключением реальных платежей нужны:

- юридический review сценария;
- пользовательские согласия на обработку персональных данных;
- политика конфиденциальности;
- договор/условия сервиса;
- выбор платёжного партнёра;
- схема токенизации карт на стороне партнёра;
- idempotency keys для всех payment intents;
- webhook signature verification;
- audit log всех платёжных событий;
- лимиты и антифрод-проверки;
- отдельное согласие на автооплату;
- понятный экран финального подтверждения суммы;
- запрет автосписания за гостя без отдельного согласия;
- хранение только provider payment method id и masked PAN;
- отсутствие CVV/CVC в системе;
- runbook для спорных списаний и failed/refunded payments.
