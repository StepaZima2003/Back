# User Flow MVP 1

## Регистрация и профиль

1. Пользователь вводит телефон.
2. Backend создаёт OTP-запрос.
3. Пользователь вводит OTP.
4. Backend создаёт или находит пользователя.
5. Пользователь заполняет имя и базовый профиль.

## Социальный слой

1. Пользователь добавляет друга по телефону.
2. Друг принимает приглашение.
3. Пользователь создаёт группу.
4. Пользователь добавляет участников группы.

## Сбор

1. Организатор создаёт сбор.
2. Добавляет участников из друзей.
3. Добавляет гостя без регистрации.
4. Добавляет ребёнка с `default_weight = 0.5`.
5. Указывает платёжного ответственного за гостя или ребёнка.
6. Добавляет расходы вручную.
7. Указывает одного или нескольких плательщиков каждого расхода.
8. Настраивает исключения по категориям или участникам.
9. Запускает расчёт.
10. Получает preview с объяснением сумм и transfer plan.

## Проверка и споры

1. Организатор отправляет расчёт участникам.
2. Участник видит свою сумму и сумму за гостей/детей, за которых платит.
3. Участник подтверждает расчёт или создаёт спор.
4. Организатор принимает или отклоняет спор.
5. При принятии спорного изменения создаётся новая версия расчёта.

## Ручная оплата

1. Участник нажимает "я оплатил".
2. Добавляет комментарий или proof URL.
3. Получатель или организатор подтверждает оплату.
4. Сбор закрывается, когда все обязательные переводы подтверждены.
